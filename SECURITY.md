# Security Policy

## Supported Versions

The project currently supports security fixes for the first public release line
only.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |
| `< 0.1.0` snapshots | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues or
pull requests.

Use one of these private channels instead:

- Email: `fabian.barney@barney-media.com`
- GitHub Security Advisories:
  [https://github.com/fabian-barney/contract-java/security/advisories/new](https://github.com/fabian-barney/contract-java/security/advisories/new)

When reporting a vulnerability, include:

- the affected version or commit
- reproduction steps or a proof of concept
- the potential impact
- any suggested remediation or mitigation

We will acknowledge valid reports promptly, investigate them privately, and
coordinate a fix and disclosure timeline before public release.
