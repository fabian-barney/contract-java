# Security Policy

## Supported Versions

Only the [latest release](https://github.com/fabian-barney/contract-java/releases/latest),
the newest minor version of the newest major version, receives security fixes.
Fixes ship in a new release; older releases and snapshots are not patched.
Upgrade to the latest release to receive them.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |
| Snapshots | No |

The supported Spring Boot, JDK, and Maven lines follow the
[support policy](RELEASING.md#support-policy).

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues or
pull requests.

Use one of these private channels instead:

- Email: `fabian.barney@barney-media.com`
- GitHub Security Advisories:
  [https://github.com/fabian-barney/contract-java/security/advisories/new](https://github.com/fabian-barney/contract-java/security/advisories/new)

When reporting a vulnerability, include:

- the affected version or commit
- reproduction steps or a proof of concept
- the potential impact
- any suggested remediation or mitigation

We will acknowledge valid reports promptly, investigate them privately, and
coordinate a fix and disclosure timeline before public release.
